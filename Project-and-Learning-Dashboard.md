# Project & Learning Dashboard

A working prototype that brings project tasks, learning notes, and a glossary into one browser workspace.

## My role

I set the product goal and visual direction, guided development with Codex, and tested the interface. My iPhone testing uncovered a rendering issue that desktop emulation missed and helped guide the compatibility work.

## What it does

- Tracks projects, tasks, and learning progress.
- Saves progress in the browser and supports backup and restore.
- Provides keyboard navigation and a reduced-motion option.

Chrome testing covered keyboard focus and layout at 400% zoom. Native Safari and VoiceOver checks remain open.
