I direct AI-assisted development: I define the goal, guide the design, review results, and request improvements. AI tools assist with implementation; I’m continuing to build my technical skills through these projects.

## Selected projects

### Growing AI Command Center

**AI-assisted product development · Interface design · Usability review**

A working dashboard prototype that brings project tracking, tasks, learning notes, a glossary, and backup controls into a tactical visual interface.

- Directed the product concept and visual direction, then refined the application through feedback and testing.
- Features include browser-based persistence, JSON backup and restore, reduced-motion controls, and a local read-only view of saved worker records.
- Used real-device feedback to identify a mobile rendering failure and drive further compatibility work.
- Development records document Chrome checks for keyboard focus, narrow layouts, and 400% zoom; native Safari and VoiceOver verification remain open.

**What it demonstrates:** turning an idea into an interactive product, communicating requirements, and treating usability defects as part of the development process.

**Status:** working prototype under refinement. Illustrative radar graphics are distinguished from actual operational records. This profile is a case study; application source is not published here.

### Growing AI Studio

**Business workflow design · AI-assisted automation · Decision-support tools**

A local prototype for developing decision worksheets for Western New York landscaping contractors. Its workflows include street-tree bid pricing and nursery delivered-cost comparison.

- Directed work toward concrete business decisions: organizing quantities and costs, comparing suppliers, and reviewing estimate assumptions.
- The Studio supports a build queue, saved feedback, and a portfolio of generated worksheets.
- The pricing workflow requires quantity and unit-cost inputs, includes overhead and target margin, and blocks incomplete cost lines.
- Research and generated findings are inputs for human review; estimators still need to check official documents and source claims.

**What it demonstrates:** connecting AI-assisted development to business operations, designing reviewable workflows, and distinguishing generated information from verified evidence.

**Status:** local prototype. Client adoption, revenue impact, and production reliability have not been established. This profile describes the work without publishing operational data or private source files.
