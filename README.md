# Project & Learning Dashboard

A browser-based workspace concept for keeping project tasks, learning notes, and a glossary together. The prototype was designed to make it easier to track what you are building and what you are learning along the way.

## What it covers

- Project and task tracking
- Learning progress and notes
- A glossary for collecting key terms
- Browser-based progress storage, with backup and restore
- Keyboard navigation and a reduced-motion option

## Accessibility and testing

Chrome checks covered keyboard focus and layout at 400% zoom. Native Safari and VoiceOver testing remain outstanding, so assistive-technology and cross-browser support have not yet been fully verified.

## Project status

This repository currently contains the project overview, not the prototype's application source code. There is no runnable demo or local setup procedure in this repository.
